# Проект: скрапинг веб сайта 'золотое яблоко'

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:```
2. Установите библиотеки из pyproject.toml:
```poetry install```

## Структура проекта:
1. Основная логика программы расположена в каталге Project/src/.
2. Файл scraper.py содержит класс Scraper для выполнения основного функцилнала по web-скрапингу сайта с использованием объектно-ориентированного подхода.
3. Файл utils.py содержит класс CSVWriter функционал записи (перезаписи) результатов сбора и обработки данных, полученных с сайта в формате CSV (см. файл FinalWork/my_products.csv).
4. В файле utils.py представлена логика вызовов классов и методов основного функционала.
5. В каталоге FinalWork/tests/ вынесена тестовая часть, для кода файлов scraper.py и CSVWriter.py соответственно.
6. В файле main.py (корень проекта) содержит функционал запуска проекта.
